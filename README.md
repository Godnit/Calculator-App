# حاسبتي
آلة حاسبة عربية تعمل دون اتصال، مع العمليات الأساسية والجذر والتربيع والنسبة والسجل.

## إخراج APK عبر GitHub
1. ارفع مجلد `calculator-android` إلى مستودع GitHub.
2. افتح تبويب **Actions** ثم شغّل **Build Hasibati APK**.
3. بعد نجاح البناء، نزّل artifact باسم `hasibati-debug-apk`.

يمكن أيضاً فتح المشروع في Android Studio واختيار **Build > Build APK(s)**.
