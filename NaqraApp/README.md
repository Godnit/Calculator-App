# نَقْرة (Naqra)

A small offline Arabic counter app for Android.

## Features
- Arabic RTL interface
- Increase, undo, and reset controls
- Saves the current count locally using Android SharedPreferences
- No internet permission and no third-party dependencies

## Build
The GitHub Actions workflow builds a debug APK from this directory and uploads it as an artifact. It also publishes a test prerelease when the build succeeds.
